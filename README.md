# KidGuard AI Ultimate

**حماية أسرية بذكاء اصطناعي محلي وتشفير كامل من الطرف إلى الطرف**

## الميزات الأساسية

- 🔐 **Zero-Knowledge E2EE** — Supabase لا يقرأ أي بيانات
- 🔗 **P2P WebRTC** — البث المباشر بين الهاتفين
- 🧠 **Local AI** — كشف المسار غير المعتاد + بصمة الحركة
- 📡 **Hybrid Sensing** — GPS + IMU + BLE + Heart Rate
- 💓 **Heartbeat Protocol** — كشف فوري لانقطاع الاتصال
- 🚗 **Anti-Theft Mode** — حماية السيارات والدراجات
- 🌍 **متعدد اللغات** — عربي/إنجليزي/فرنسي/إسباني
- 🎨 **تصميم عصري** — Glassmorphism + Dark Mode
